# Steamcommunity 302 (optional, community tool)

Steamcommunity 302 is a community proxy that makes the Steam store/community reachable
from mainland China. It is not part of this port and not redistributed here; install it
only if you need it.

## Reference installation

- binaries: `/var/lib/Steamcommunity_302/app/versions/15.0.9/`
- data/runtime: `/var/lib/Steamcommunity_302/`, `/run/s302/1000/`
- unit: `s302/s302-1000.service`
- credential file: `/home/alarm/.config/Steamcommunity_302/control.token` (created by the
  GUI on first run; **never commit or share it**)

## Install

1. Download the ARM64 CLI/AppImage release from the project's releases page (v15.0.9 is
   what the reference device runs) and unpack it under
   `/var/lib/Steamcommunity_302/app/versions/15.0.9/`.
2. Copy `s302/s302-1000.service` to `/etc/systemd/system/`, adjust the version path and
   username if they differ, then:
   `systemctl daemon-reload && systemctl enable --now s302-1000.service`
3. Start the GUI once as the desktop user to generate the control token and the hosts
   file. The service runs with `--allowed-uid 1000`.

## Notes

- This kernel has no NFQUEUE, so the tool must run in **hosts mode**. Do not enable the
  transparent-proxy mode.
- The IPC socket is created as `0666` by the service wrapper on the reference device so
  the desktop GUI can talk to it.
- It rewrites `/etc/hosts`; backups are kept under `/var/lib/Steamcommunity_302/hosts-backups/`.
  Review them before uninstalling.
